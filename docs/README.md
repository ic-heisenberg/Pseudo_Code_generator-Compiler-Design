## FAQs

**Q: What is pseudo code?**
A: Pseudo code is a simplified, language-independent representation of an algorithm or program logic.

**Q: Can I use this compiler in production?**
A: Yes, this compiler is production-ready. See the [Release Notes](./releases/notes.md) for version information.

**Q: How do I report bugs?**
A: Please open an issue on [GitHub Issues](https://github.com/ic-heisenberg/Pseudo_Code_generator-Compiler-Design/issues).
